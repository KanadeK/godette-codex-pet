# Code of conduct

## Our standard

Contributors and maintainers will keep participation respectful, specific, and
welcoming. Helpful behavior includes constructive review, clear technical
evidence, credit for work, respect for licenses, and patience with different
languages and experience levels.

Harassment, discriminatory language, threats, sexualized attention, doxxing,
publishing private content, deliberate license violations, and sustained
personal attacks are unacceptable.

## Scope

This standard applies in repository issues, pull requests, discussions, release
notes, and other public spaces used to represent this project.

## Enforcement

Report conduct concerns privately to the repository owner through the contact
method on the owner's GitHub profile. Include links or screenshots when safe.
Maintainers may edit or remove content, issue a warning, temporarily restrict
participation, or permanently ban participation in proportion to the behavior.

Reports will be reviewed without retaliation. Details are shared only as needed
to investigate and act.
