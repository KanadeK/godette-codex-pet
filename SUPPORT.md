# Support

Use GitHub Discussions for usage questions and policy design. Open an issue for
a reproducible bug, documentation error, or accessibility regression.

Before asking for help, run:

```bash
godette-pet doctor --source pet --json
godette-pet validate pet --strict --json
```

For PetDiff failures, attach `report.json` and `diff-sheet.png`. Do not attach
raw Codex logs, prompts, tool inputs/outputs, private paths, email addresses, or
account data.

Report security problems through private vulnerability reporting as described
in `SECURITY.md`.
